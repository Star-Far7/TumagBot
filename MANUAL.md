## 1. Что делает бот

Бот фотографирует накладную → распознаёт товары через ИИ → сопоставляет их
с вашей базой из Umag → выдаёт готовый Excel-файл для загрузки обратно в Umag.

**Что автоматизируется:**
- Ручной ввод позиций из бумажной накладной
- Поиск «как этот товар называется у нас в базе»
- Сравнение старых и новых закупочных цен
- Сборка многостраничных накладных в один файл

**Самообучение:** каждый раз, когда вы вручную выбираете соответствие
«название поставщика → товар в базе», бот запоминает его навсегда.
При следующей накладной от того же поставщика этот товар определится
автоматически.

## 2. Первоначальная настройка

### Шаг 1 — Создать бота в Telegram

1. Откройте Telegram, найдите `@BotFather`
2. Отправьте `/newbot`
3. Введите имя бота (например: `Umag Накладные`)
4. Введите username бота (например: `umag_invoices_bot`) — должен заканчиваться на `bot`
5. Скопируйте **токен** вида `7123456789:AAF...` — он понадобится ниже

**Включить инлайн-режим** (для поиска товаров из любого чата):

1. В `@BotFather` → `/mybots` → выберите бота
2. `Bot Settings` → `Inline Mode` → `Turn on`

### Шаг 2 — Получить ключ Gemini API

1. Перейдите на https://aistudio.google.com
2. Войдите через Google-аккаунт
3. Нажмите `Get API key` → `Create API key`
4. Скопируйте ключ вида `AIzaSy...`

> Бесплатный тариф Gemini Flash позволяет обрабатывать ~1500 накладных в день.

### Шаг 3 — Узнать свой Telegram ID

1. Напишите боту `@userinfobot` любое сообщение
2. Он ответит вашим ID — число вида `123456789`

### Шаг 4 — Создать файл настроек

В папке `umag_bot` создайте файл `.env` (скопируйте из `.env.example`
и заполните):

```
BOT_TOKEN=7123456789:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
ALLOWED_USERS=123456789
```

Если ботом будут пользоваться несколько продавцов — перечислите их ID
через запятую:

```
ALLOWED_USERS=123456789,987654321,555000111
```

Если оставить `ALLOWED_USERS=` пустым — бот доступен всем желающим.

## 3. Запуск бота

### Требования

- Python 3.10 или новее
- Установленные зависимости (делается один раз)

### Установка зависимостей (один раз)

Откройте командную строку / PowerShell в папке проекта:

```
cd "D:\Проекты\Claude Code\umag_bot"
pip install -r requirements.txt
```

### Запуск

```
python main.py
```

Если всё настроено правильно, в консоли появится:

```
2025-05-26 10:00:00  __main__  INFO  Бот запущен. Нажмите Ctrl+C для остановки.
```

Напишите боту `/start` в Telegram — он должен ответить.

### Остановка

Нажмите `Ctrl + C` в консоли.

### Автозапуск на Windows (опционально)

Создайте файл `start_bot.bat` в папке проекта:

```batch
@echo off
cd /d "D:\Проекты\Claude Code\umag_bot"
python main.py
pause
```

Двойной клик по этому файлу будет запускать бота.

## 4. Загрузка каталога товаров

Бот ищет товары в собственной базе. Эту базу нужно заполнить из Umag.

### Шаг 1 — Выгрузить товары из Umag

В Umag найдите функцию экспорта/выгрузки товаров в Excel или CSV.
Обычно она называется «Экспорт», «Выгрузка» или находится в разделе «Товары».

Файл должен содержать хотя бы колонку с названиями товаров.
Бот также распознаёт колонки:

| Колонка в файле | Что ищет бот |
|---|---|
| Наименование / Название / Товар | название (обязательно) |
| ID / Код / Артикул / Внешний код | уникальный идентификатор |
| Штрихкод / Barcode / EAN | штрихкод |
| Категория / Группа | группа товаров |
| Ед.изм. / Единица / Unit | единица измерения |
| Цена закупа / Закупочная цена | цена |

### Шаг 2 — Отправить файл боту

1. Отправьте боту команду `/upload`
2. Бот попросит прислать файл
3. Прикрепите и отправьте файл Excel (.xlsx) или CSV (.csv)

Бот ответит:
```
✅ Каталог обновлён!
Строк обработано: 1 250
Товаров в базе: 1 250
```

### Обновление каталога

Повторяйте этот процесс когда угодно — бот обновит существующие товары
и добавит новые. Псевдонимы поставщиков при этом **не удаляются**.

## 5. Обработка накладной

### Шаг 1 — Сфотографировать накладную

**Рекомендации для хорошего фото:**
- Весь лист должен быть в кадре
- Хорошее равномерное освещение, без теней
- Камера держится параллельно листу (не под углом)
- Текст чёткий, не смазан

### Шаг 2 — Отправить фото боту

Просто отправьте фото в чат с ботом — без команды, без подписи.

Бот начнёт работу:
```
🔍 Читаю накладную через Gemini AI…
🤖 Распознаю товары…
⚙️ Найдено 24 позиции, ищу в базе…
```

После обработки бот покажет статистику:
```
✅ Распознано 24 позиции
⚡ По псевдонимам: 18
🔖 По штрихкоду: 2
🤖 Авто (требуют OK): 3
❓ Нужен выбор: 1
```

### Шаг 3 — Подтвердить сопоставление

Бот будет показывать позиции, требующие вашего участия, по одной.

**Вариант А — авто-совпадение (бот нашёл с высокой уверенностью):**

```
📦 Позиция 1/4
Из накладной: Молоко ультрапастеризованное 3.2% 1л
Кол-во: 10 шт × 90.00
💰 Цена: 80.00 → 90.00 (+12.5%)

🤖 Авто-совпадение:
[✅ Молоко у/п 3.2% 1л (92%)]
[🔄 Другой товар]  [⏭ Пропустить]
```

- Нажмите **✅** если совпадение верное → бот запомнит это навсегда
- Нажмите **🔄 Другой товар** если нужен другой товар → откроется ручной поиск
- Нажмите **⏭ Пропустить** если товар не нужен в накладной

**Вариант Б — бот предлагает варианты:**

```
📦 Позиция 2/4
Из накладной: йогурт питьевой клубника 500г
Кол-во: 6 шт × 55.00

❓ Выберите из базы:
[67%] Йогурт питьевой клубника 0.5л
[54%] Йогурт питьевой персик 500г
[48%] Йогурт питьевой черника 500г
[🔍 Найти вручную]  [⏭ Пропустить]
```

Нажмите на нужный товар. Бот сохранит это соответствие и в следующий
раз определит «йогурт питьевой клубника 500г» автоматически.

**Вариант В — ручной поиск:**

Нажмите **🔍 Найти вручную**, затем введите часть названия:
```
клубн
```
Бот покажет список совпадений — нажмите нужный.

### Шаг 4 — Получить Excel

После обработки всех позиций бот покажет итог:

```
✅ Накладная обработана!
📦 Принято позиций: 23
⏭ Пропущено: 1
💰 Изменений цен: 4

[📥 Скачать Excel для Umag]
```

Нажмите кнопку — бот пришлёт файл `.xlsx`.

### Многостраничные накладные

Если накладная занимает несколько листов — отправляйте фото по одному.
**Важно:** отправляйте следующее фото только после того, как бот обработал
предыдущее и перешёл к следующему листу.

> В текущей версии каждое фото = отдельная сессия. Для объединения
> нескольких листов в один Excel — обработайте каждый отдельно,
> затем объедините файлы в Excel вручную (скопируйте строки).

### Отмена

Если нужно прервать обработку: `/cancel`

## 6. Инлайн-поиск товаров

Позволяет искать товары прямо из любого чата в Telegram, не открывая бота.

**Как использовать:**

В строке ввода любого чата введите `@имя_вашего_бота` и пробел, затем
название товара:

```
@umag_invoices_bot молоко 3.2
```

Появится выпадающий список с товарами из вашей базы. Нажмите на товар —
его карточка отправится в чат.

**Применение:**
- Быстро узнать штрихкод товара
- Проверить закупочную цену не открывая Umag
- Найти правильное название товара при общении с поставщиком

## 7. Управление псевдонимами

Псевдонимы — это сохранённые соответствия между названиями поставщика
и товарами в вашей базе. Чем больше накладных обработано, тем меньше
ручной работы.

**Просмотр псевдонимов:**

```
/aliases
```

Бот покажет список (топ-25 по частоте использования):

```
📚 Псевдонимы поставщиков (топ-25 по частоте):

• молоко ультрапаст 3.2% 1л
  → Молоко у/п 3.2% 1л  (×47)

• кефир питьевой 2.5% пэт
  → Кефир 2.5% 0.9л  (×31)
```

**Как удалить неверный псевдоним:**

Сейчас — через команду `/cancel` во время ошибочного подтверждения.
В будущих версиях планируется команда `/del_alias`.

## 9. Формат Excel-файла

Бот генерирует файл с двумя листами.

### Лист «Накладная»

Готов для импорта в Umag. Содержит колонки:

| # | Колонка | Описание |
|---|---|---|
| A | Штрихкод | Штрихкод из вашей базы |
| B | Наименование | Название товара из вашей базы |
| C | Из накладной | Оригинальное название от поставщика (если отличается) |
| D | Категория | Группа товара |
| E | Ед.изм. | Единица измерения |
| F | Кол-во | Количество |
| G | Цена закупа | Новая цена |
| H | Сумма | Кол-во × Цена |
| I | Стар. цена | Цена из предыдущей накладной |
| J | Изм. % | Изменение цены в процентах |

**Цветовая подсветка:**

- 🔴 Красный фон — цена выросла
- 🟢 Зелёный фон — цена снизилась
- ⬜ Серый фон — позиция была пропущена

### Лист «Изменения цен»

Создаётся автоматически если есть изменения цен. Показывает только
товары, у которых изменилась цена закупа, отсортированные по величине
изменения (сначала самые подорожавшие).

## 10. Перенос на сервер

Когда нужно, чтобы бот работал круглосуточно без включённого ноутбука.

### Что арендовать

Минимальный VPS: 1 vCPU, 512 MB RAM, 10 GB SSD.
Подойдут: Timeweb Cloud, REG.RU, Selectel, DigitalOcean.
ОС: Ubuntu 22.04.

### Перенос файлов

1. Скопируйте всю папку `umag_bot` на сервер (через WinSCP или FileZilla)
2. **Не копируйте** файл `.env` — создайте его заново на сервере

### Установка на сервере (Ubuntu)

```bash
# Установить Python и pip
sudo apt update && sudo apt install python3 python3-pip -y

# Перейти в папку бота
cd ~/umag_bot

# Установить зависимости
pip3 install -r requirements.txt

# Создать .env файл
nano .env
# Вставить содержимое, сохранить (Ctrl+O, Enter, Ctrl+X)
```

### Запуск как фоновый сервис (systemd)

Создайте файл сервиса:

```bash
sudo nano /etc/systemd/system/umag_bot.service
```

Вставьте (замените `username` на имя вашего пользователя):

```ini
[Unit]
Description=Umag Invoice Bot
After=network.target

[Service]
Type=simple
User=username
WorkingDirectory=/home/username/umag_bot
ExecStart=/usr/bin/python3 main.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Запустите:

```bash
sudo systemctl daemon-reload
sudo systemctl enable umag_bot
sudo systemctl start umag_bot

# Проверить статус
sudo systemctl status umag_bot

# Смотреть логи в реальном времени
sudo journalctl -u umag_bot -f
```

## 11. Частые вопросы

**Бот не отвечает на `/start`**

- Проверьте, запущен ли `python main.py` — в консоли не должно быть ошибок
- Убедитесь, что `BOT_TOKEN` в `.env` скопирован без лишних пробелов
- Проверьте, что ваш Telegram ID есть в `ALLOWED_USERS`
  (или `ALLOWED_USERS` пустой)

**Gemini не распознаёт накладную**

- Сфотографируйте чётче: весь лист в кадре, без теней, хорошее освещение
- Попробуйте PDF-скан если есть возможность сохранить как фото
- Накладные от руки распознаются хуже — лучше работает машинопечатный текст

**Бот отвечает «База товаров пуста»**

Сначала нужно загрузить каталог: `/upload` → отправьте файл из Umag.

**Бот не находит нужный товар даже при ручном поиске**

Товара нет в базе. Обновите каталог из Umag (`/upload` с новым файлом).
Если товар новый — добавьте его сначала в Umag, потом обновите каталог.

**Как обновить базу товаров**

Выгрузите актуальный каталог из Umag и снова отправьте боту.
Существующие товары обновятся, новые добавятся, псевдонимы сохранятся.

**Накладная на несколько листов**

Обрабатывайте каждый лист как отдельное фото. Дождитесь завершения
обработки предыдущего перед отправкой следующего.

**Бот подобрал неверный товар автоматически**

При появлении варианта нажмите **🔄 Другой товар** и выберите правильный.
Неверный псевдоним будет перезаписан.

**Файл `.env` не создаётся / не видно расширение**

В Windows Explorer: Вид → Расширения имён файлов → включить.
Создайте файл через Блокнот: Файл → Сохранить как → в поле «Тип файла»
выберите «Все файлы» → имя файла `.env` → Сохранить.

**Можно ли использовать бота с телефона**

Да. Telegram работает на любом устройстве. Фото накладной можно
сделать прямо с телефона и сразу отправить боту.
